# Pagos y donaciones

Modelo definitivo: transferencia directa.

- La plataforma NO actúa como intermediaria financiera ni custodia fondos.
- No hay pasarelas de pago, billeteras ni saldos en el MVP.
- Las donaciones son compromisos de aporte; la transferencia se realiza directamente entre donante y beneficiario/acreedor.
- Se registran: aporte comprometido, transferencia informada, recepción confirmada y deuda pagada.
- Los datos bancarios se comparten solo con autorización del beneficiario.
- Para deudas, priorizar canales oficiales del acreedor.
- No integrar Flow/Transbank/Mercado Pago mientras el modelo sea de transferencia directa.
